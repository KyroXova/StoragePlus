# Storage Plus

Storage Plus is a Minecraft storage mod that provides expanded storage solutions including Compartments, Barrels, and tiered storage blocks.

## Overview

Storage Plus introduces custom storage blocks designed to provide expanded inventory capacity within a single block footprint:

- **Compartments**: High-capacity chest blocks providing expanded storage space beyond standard vanilla chests within a single block.
- **Barrels**: Compact storage blocks available in multiple material variants (such as Wood, Iron, and higher tier materials) offering larger storage space based on the materials used to craft them.

## Supported Minecraft Versions

Storage Plus is planned to support multiple Minecraft versions across development, starting with:

- Minecraft 1.7.9 / 1.7.10 (Initial Development Target)
- Minecraft 1.12.2
- Minecraft 1.16.5

Additional Minecraft versions are planned as development progresses.
