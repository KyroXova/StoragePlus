# Storage Plus

Storage Plus is a storage mod for Minecraft Forge that adds expanded storage blocks, including Compartments and tiered Barrels.

## Features

### Compartments
Compartments are high-capacity chest blocks that offer significantly more storage space than standard vanilla chests within a single block footprint.

### Barrels and Material Variants
Barrels provide compact storage options available in multiple material tiers, including standard Wood, Iron, and higher material variants. Higher tier materials provide progressively larger storage space.

## Supported Versions
Initial releases target Minecraft 1.7.9 / 1.7.10, with versions for 1.12.2, 1.16.5, and further Minecraft versions planned.
